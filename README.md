# Hospital Management System

A comprehensive **Hospital Management System** designed to streamline patient registration, appointment scheduling, and doctor-patient interaction. This web-based application aims to enhance the efficiency of hospital operations, ensuring smooth management of patient records, appointments, and feedback, while maintaining high reliability and security.

## Features

- **Patient Registration**: Streamlined process for registering new patients with essential details.
- **Appointment Scheduling**: Enables patients to book appointments with available doctors.
- **Doctor & Patient List Views**: Simplified interfaces for managing patient and doctor information.
- **Feedback System**: Patients can provide feedback after their appointments.
- **Database Integration**: Scalable and secure database for storing and managing patient and doctor information.

## Tech Stack

- **Frontend**: JSP,HTML, CSS, JavaScript
- **Backend**: Servlets, JDBC, MySQL
- **Database**: MySQL for secure and scalable data storage
- **Tools**: IntelliJ Idea, MySQL Workbench, Apache Tomcat for server management

## Project Structure

- **JSP**: For rendering the frontend, including forms for patient registration and appointment booking.
- **Servlets**: For handling business logic and processing data sent from the frontend to the backend.
- **JDBC**: For connecting and interacting with the MySQL database.
- **CSS/JavaScript**: For UI styling and client-side interactivity.
